# Jiayi Ma Academic Homepage

Independent academic homepage for Professor Jiayi Ma, based on a locally held
website template and maintained as a standalone project.

## Publication data

- The publication list is synchronised every six hours from the original public Google
  Sites page, so newly added or edited publication records are reflected here automatically.
- Paper links use exact-title Crossref records first, preferring publisher URLs
  from DOI metadata.
- Code links are added only when a GitHub repository or public abstract gives a
  high-confidence match.
- Citation badges, total citations, and h-index are refreshed from the public Google
  Scholar profile on the same schedule. If Scholar presents a CAPTCHA or rate limit,
  the last successful values stay published until the next successful refresh.
