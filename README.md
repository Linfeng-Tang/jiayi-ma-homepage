# Jiayi Ma Academic Homepage

Independent academic homepage for Professor Jiayi Ma, based on a locally held
website template and maintained as a standalone project.

## Publication data

- The publication list is synchronised daily from the original public Google
  Sites page.
- Paper links use exact-title Crossref records first, preferring publisher URLs
  from DOI metadata.
- Code links are added only when a GitHub repository or public abstract gives a
  high-confidence match.
- Citation badges are refreshed from the public Google Scholar profile.
